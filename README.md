# OCD-Patient-Clinical-Analytics
SQL-based clinical data analytics project exploring OCD patient demographics, symptoms, treatment patterns, and Y-BOCS severity scores.

## Project Overview
This project focuses on analyzing clinical data of patients diagnosed with Obsessive-Compulsive Disorder (OCD) using SQL.

The objective is to explore patient demographics, symptoms, medication patterns, and clinical severity using SQL queries.

## Tools & Technologies
- MySQL


## Key Analysis Performed
1. Total patient count
2. Gender distribution
3. Average patient age
4. Most common obsession types
5. Most common compulsion types
6. Average Y-BOCS scores
7. Depression and anxiety comorbidity
8. Y-BOCS scores by ethnicity
9. Family history and OCD severity
10. Most prescribed medications
11. Symptom duration by marital status
12. Patient severity ranking using DENSE_RANK()
13. Patients exceeding the cohort average
14. Cumulative patient counts by diagnosis year
15. Patient severity classification using CASE WHEN

## SQL Concepts Used
- SELECT, WHERE, GROUP BY
- ORDER BY
- Aggregate Functions
- CASE WHEN
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- DENSE_RANK()
